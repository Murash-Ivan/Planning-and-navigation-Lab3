# Lab-3

Лабораторная работа №3: реализация системы управления, одометрии и визуализации для IoTRobotWorld

Полная реализация серверного приложения на C# (WinForms) для управления мобильным роботом в симуляторе IoTRobotWorld. Проект включает сетевое взаимодействие, алгоритмы автономного движения, математическую модель одометрии и систему визуализации карты на основе геометрических преобразований.

Основные реализованные модули:

Сетевое взаимодействие и парсинг (UDP/JSON)
- Настроен асинхронный UDP-клиент для двустороннего обмена данными с симулятором.
- Реализован ручной парсинг входящих JSON-сообщений (телеметрия, показания 8 дальномеров, 5 датчиков линии, энкодеры, смарт-камера).
- Формирование и отправка исходящих JSON-команд управления (тяга F, баланс B).

Алгоритмы управления движением
- Ручное управление: интерфейс с ползунками, кнопками и поддержкой клавиатуры (WASD / Стрелки).
- Автоматическое движение (следование по линии): реализован автомат из 4 фаз.
  1. Поиск линии (поворот на месте).
  2. Сближение и детекция (движение прямо до срабатывания датчиков/камеры).
  3. Выравнивание (короткий разворот для захвата оси трассы).
  4. Удержание на линии (П-образный регулятор на основе взвешенной суммы показаний датчиков) с программной компенсацией ложных срабатываний на стены и обработкой пунктирной линии.
- Аварийный объезд препятствий по данным фронтальных дальномеров и контактного бампера.

Одометрия
- Математическая модель расчета глобальных координат (X, Y) и курса (Theta) исключительно по показаниям колесных энкодеров.
- Учтены физические параметры шасси: база 0.40 м, диаметр колеса 16.51 см, разрешение энкодера 200 тиков/об.
- Реализована корректная обработка сброса позиции.

Геометрические преобразования и визуализация
- Пересчет локальных полярных координат препятствий (с 8 дальномеров) в глобальную декартову систему координат карты.
- Учет габаритов робота: к дистанции дальномера прибавляется радиус корпуса (0.30 м) для корректного наложения карты на траекторию.
- Отрисовка в реальном времени на графическом холсте (PictureBox):
  * Непрерывная траектория движения (накопительная отрисовка).
  * Карта обнаруженных препятствий (фильтрация шумов > 3 метров).
  * Габариты и текущий курс робота.
- Функция «Сброс»: очистка карты и возврат расчетных координат в стартовую позицию (0.75; 0.75).
